# Companion deposit package

Prepared for the paper **When Does AI Beam Prediction Save Radio Resources?** by Deepak Singh.

The package includes the current merged manuscript, four vector figures, editable architecture source, scientific scripts, numerical outputs, protocol/amendment history, independent reconstruction checks, and fresh clean-directory reproduction logs. `SOURCE_PACKAGE_MANIFEST.json` lists every included path, byte size and SHA-256 digest.

Raw/prepared third-party channel data, standards PDFs, model caches and third-party software packages are excluded. `data_pilot/README.md` documents input retrieval and preparation, and `AUTHOR_REPRODUCTION.md` states the exact expected input hash. Keep dataset/software rights separate; no new blanket license is assigned by this package.

Proposed destination: a dedicated public `ai-beam-resource-accounting` repository under the user's GitHub account. No matching repository exists through the connected account, and the current connector cannot create repositories. No public URL or DOI has been established. This file documents a prepared deposit, not a completed upload.

After deposition, add the actual stable URL or DOI to the manuscript acknowledgment/data-availability text and the citation metadata. No submission to a journal has been made.
